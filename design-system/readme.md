# KT nasmedia · OpenAI Ads Design System

랜딩 페이지의 "전체 인상·완성도" 문제를 값의 일관성 차원에서 해결하기 위해 만든 시스템입니다.

## 왜 만들었나

`/v2` 스타일시트를 실측한 결과입니다.

| 항목 | 정리 전 | 정리 후 |
|---|---|---|
| font-size | 21종 (11.5–26px, 0.5px 단위) | **8단계** |
| font-weight | 7종 | **4단계** |
| border-radius | 12종 | **5단계** |
| line-height | 11종 | **4단계** |
| 여백 px | 38종 | **10단계 (8px 그리드)** |
| 색상 | hex 17 + rgba 26 하드코딩 | **역할 토큰만** |

개별 요소는 문제가 없는데 전체가 정돈돼 보이지 않았던 원인입니다. 값이 매번 즉흥적으로
정해져 화면에 리듬이 없었습니다.

## 규칙

1. **스케일 밖의 값을 쓰지 않는다.** 15.5px, 19px 같은 임의 크기와 13px, 26px 같은
   그리드 밖 여백을 금지합니다.
2. **색은 역할로만 쓴다.** accent(블루)는 상호작용과 화면당 강조 1회,
   positive(민트)는 '결과·완료' 의미일 때만, brand(레드)는 로고 전용입니다.
   장식 목적으로 색을 얹지 않습니다.
3. **본문은 18px / 행간 1.8 / 굵기 500.** 국문 본문 행폭은 28자 이상을 확보합니다.
4. **주 버튼은 화면당 한 개.**

## 구성

- `tokens/` — colors, typography, spacing, effects
- `guidelines/` — 타입 스케일, 색 역할, 여백 스케일
- `components/` — 표면·카드, 버튼·배지
- `styles.css` — 토큰 일괄 import

## 적용

`/v3` 라우트가 이 토큰 위에서 만들어집니다. 운영 페이지(`/`)와 이전 검토본(`/v2`)은
그대로 두고 비교용으로 병행 운영합니다.
